# Java Compound Interest Calculator

## Overview

This project is a Java-based investment calculator that compares simple interest with compound interest. It demonstrates how an initial investment can grow over time under a fixed annual interest rate.

I created this project to combine my interest in finance and investing with the Java programming concepts I am learning in AP Computer Science A.

## Features

- Accepts an initial investment, annual interest rate, and investment period.
- Calculates the final value using simple interest.
- Calculates compound growth year by year.
- Displays the amount of interest earned under each method.
- Compares the results to show the additional growth from compounding.

## Technologies

- Java
- Java Scanner for user input
- Loops and conditional statements
- Arithmetic operations and formatted output

## Example

**Inputs**
- Initial investment: $1,000
- Annual interest rate: 5%
- Investment period: 10 years

**Expected results**
- Simple interest value: $1,500.00
- Compound interest value: $1,628.89
- Additional growth from compounding: $128.89

## How to Run

1. Install a Java Development Kit (JDK).
2. Download `Main.java` from this repository.
3. Open a terminal in the folder containing the file.
4. Compile the program by running:

   `javac Main.java`

5. Start the program by running:

   `java Main`

6. Enter the requested investment information.
